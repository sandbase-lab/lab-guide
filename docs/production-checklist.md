# 从原型到生产 / Production checklist

这份清单用于决定下一步工作。勾选条目并不自动证明项目已经适合生产；每项应链接到代码、评估或运行证据。不适用项需要说明原因。

## 效果与边界

- [ ] 定义目标用户、交付结果、验收标准和不支持的任务。
- [ ] 用代表性输入评估质量，包括失败、空数据和异常工具返回。
- [ ] 记录样本量、日期、模型与代码版本、成功率和人工复核方式。
- [ ] 区分真实运行、模拟样例和已录制演示。

## 成本与可靠性

- [ ] 记录实测延迟与费用，设置单任务预算和调用上限。
- [ ] 配置超时与可重试错误；避免对不确定结果盲目重复执行。
- [ ] 定义并发和速率限制，处理服务不可用与任务中断。
- [ ] 异步任务可查状态；需要时支持取消、持久化和恢复。
- [ ] 对外部写操作使用适当的幂等或去重机制。

## 权限与数据

- [ ] 按任务授予最小权限，服务端保存凭据，日志中脱敏。
- [ ] 不可信输入与工具结果不会自行扩大权限或授权。
- [ ] 对发布、发送、购买等行为定义明确授权条件。
- [ ] 明确数据存储位置、保留期限与删除方式。
- [ ] Sandbox 的网络、资源和文件访问范围适合实际任务。

## 部署与运营

- [ ] 在目标部署环境验证启动、健康检查和配置管理。
- [ ] 用任务标识关联日志、工具调用和结果。
- [ ] 定义质量、延迟、失败和预算异常的监控指标。
- [ ] 验证恢复、回滚和依赖升级方式。
- [ ] 明确维护者、支持的版本及事件响应方式。

## 发布证据

在 README 中链接评估、部署说明、已知限制和最后验证日期。声明生产就绪时，写明验证覆盖的负载和环境，不将结论推广到未验证场景。
