# Contributing

We welcome reproducible agent projects, evaluation cases, bug reports, documentation, and production lessons.

## Propose a project

Use the [lab proposal template](https://github.com/sandbase-lab/lab-guide/issues/new?template=lab-proposal.md). Describe the task, target user, actual result, dependencies, costs, reproduction steps, and maintainer. Proposed projects enter the directory only after meeting the Experimental requirements.

## Update this guide

1. Fork the repository and make a focused change on a branch.
2. Check accuracy and links. Support workflow claims with evidence.
3. Open a pull request describing the problem, change, and verification.

Directory entries include name, task, repository, preview, stage, setup instructions, dependencies, cost evidence, maintainer, and last validation date.

## Contribute to an agent

Open an issue or pull request in the relevant project repository and follow its evaluation instructions. Organization membership is not required.

Do not submit secrets, unauthorized data, or third-party assets you cannot share. Respect the license and other contributors. Report security issues privately following the [security policy](https://github.com/sandbase-lab/.github/blob/main/SECURITY.md).
